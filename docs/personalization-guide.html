Website Handoff

Personalization Guide

Everything you need to change to make the chapter website yours — and exactly where to find it. Work top to bottom; the first sections cover most of what matters.

Priority Essential Do before launch Recommended Do soon Optional Polish anytime

✎ Most content lives in plain configuration files — you change the text between quotes, save, and preview with npm run dev. After editing, deploy to publish. File paths below are relative to the project folder; use the Copy button to grab one.

01

Core chapter identity

Essential

One file drives the site name, footer, contact info, social links, and homepage stats.

Filesrc/config/site.ts
FieldWhat it is
organizationFraternity name — "Alpha Sigma Phi"
chapterYour chapter — "Theta Tau Chapter"
universitySchool — "Quinnipiac University"
taglineShort slogan shown in the hero and footer
contactEmailShown in the footer and "Contact" buttons
valuesMotto words, shown as chips in the hero (see note)
socialsInstagram / Facebook / LinkedIn / Email — update each link + handle
statsThe four big homepage numbers
Heads up: values is currently one combined entry, so it renders as a single chip. To show them separately, split it into individual strings: ["Silence", "Charity", "Purity", "Honor", "Patriotism"]. Leave url alone — set the real domain via NEXT_PUBLIC_SITE_URL (next section).
02

Secrets & links

Essential

Environment variables aren't committed to git. Set them locally, and again in Vercel when you deploy.

File.env.local
VariableWhat it does
ADMIN_PASSWORDPassword to sign in at /admin. Change this.
ADMIN_SESSION_SECRETRandom ≥16-char string securing logins. Generate with openssl rand -base64 32.
NEXT_PUBLIC_SITE_URLYour real domain (for search & social sharing).
NEXT_PUBLIC_NEWSLETTER_URLOptional shortcut to change the newsletter link.
GOOGLE_CALENDAR_ICS_URLSync events from Google Calendar (Section 04).
GOOGLE_SHEET_CSV_URLSync the roster from a Google Sheet (Section 03).
03

Brothers roster

Essential

Two ways to manage the roster — pick one.

  • Google Sheet (recommended, no code): set GOOGLE_SHEET_CSV_URL to a published sheet, then keep it current via the sheet or a linked Google Form.
  • Edit the file directly: each brother is an object you can copy and edit.
Option BFilesrc/data/brothers.ts
// Copy a block and edit the fields
{
  firstName: "First", lastName: "Last",
  classYear: 2027,
  major: "Finance",
  position: "President",      // omit for a regular member
  imageUrl: "https://…/headshot.jpg", // blank = initials avatar
  isExecutiveBoard: true,     // shows in the Exec Board section
  isActive: true,            // false = hidden from the site
}
Replace the placeholders: the names in this file are fictional. To remove someone, set isActive: false (keeps history) or delete the block.
04

Events & calendar

Recommended

Two ways — pick one.

  • Google Calendar (recommended): set GOOGLE_CALENDAR_ICS_URL and manage everything in Google Calendar. Recurring events and categories are handled for you.
  • Edit the file directly.
Option BFilesrc/data/events.ts
{
  title: "Welcome Back BBQ",
  startDate: "2026-08-25T17:00:00",
  endDate: "2026-08-25T20:00:00",   // optional
  location: "The Quad",
  category: "Brotherhood",          // drives the color
  isPublic: true,                  // false = hidden
}

Categories: Brotherhood, Recruitment, Philanthropy, Social, Academic, Chapter, Alumni, University, Other.

06

Recruitment & IFC forms

Recommended

Edit the recruitment copy, and paste your real IFC / chapter form links.

Filesrc/config/recruitment.ts
// A blank url shows a "Link coming soon" chip until you add it
{
  title: "IFC New Member Registration",
  description: "Register your intake with the Quinnipiac IFC.",
  url: "https://…",   // ← your link here
  required: true,
}

Recruitment events on this page come automatically from your calendar — anything with the category Recruitment shows up here.

07

Welcome Week Potluck

Optional
  • Turn on/off: use the toggle in the admin dashboard (/admin), or set FEATURE_POTLUCK.
  • Intro text: src/app/(public)/potluck/page.tsx (the two paragraphs up top).
  • Sample sign-ups: src/data/potluck.ts — delete once real ones arrive, or from the admin page.
08

Feature flags

Recommended

Turn whole pages on or off.

Filesrc/config/features.ts
defaultFeatures = {
  brothers: true, events: true, newsletter: true,
  about: true, potluck: true, recruitment: true,
  alumni: false, donations: false, // reserved for later
}

potluck and recruitment can also be flipped live from the admin dashboard — no redeploy needed.

10

Branding — crest, colors, favicon

Optional
  • Crest letters & wordmark: src/components/brand/logo.tsx (swap the drawn crest for a logo image if you have one).
  • Colors: tailwind.config.ts — the palette is navy, cardinal (the red accent), and stone neutrals.
  • Favicon: replace src/app/favicon.ico with your own (same filename).
11

Admin access

Essential

Sign in at /admin/login with ADMIN_PASSWORD. From the dashboard you can toggle features, view & delete potluck sign-ups, export them as CSV, and review the current roster, events, and newsletter.

Before launch: set a strong ADMIN_PASSWORD and a random ADMIN_SESSION_SECRET, and add both in Vercel.
